### Artifact language for this project

This project declares the language of each kind of artifact (its standards package, copied into .dw-told-ai/project.json). It replaces the English default (DW Flow's ground rules; the agent contract, section C):

| Artifact | Language | Covers |
|---|---|---|
| code | English | code, identifiers, comments, tests, configuration, scripts, schemas |
| docs | English | README files, guides, API documentation |
| specification | English | the living specification, dw-ai/openspec/specs/ |
| plans | Spanish (neutral, professional: no voseo, no regional slang) | the DW Flow story plan dw-flow/<ID>.md |
| sdd-reports | English | the DW Review reports under .dw-told-ai/review/<ID>/ |
| commits | Spanish (neutral, professional: no voseo, no regional slang) | commit title and body; the Conventional Commits type and scope are keywords and stay in English |
| pull-requests | Spanish (neutral, professional: no voseo, no regional slang) | pull request title and description |
| tracker | Spanish (neutral, professional: no voseo, no regional slang) | everything written into the ticket tracker |

Precedence, highest first: an explicit request from the user for that artifact; a file being extended keeps its language; this table; English.
Always, whatever the table says: talk to the user in their language; on-screen messages stay in the product's language, exactly as they will appear; table and field names are written exactly as in the system; code, paths, identifiers, commands and quoted errors stay verbatim inside a Spanish text. Commits keep the Conventional Commits type and scope in English.
